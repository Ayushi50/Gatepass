## Bug found by the browser run

After a hold expired, the live "Pay" button stayed visible beside the disabled one. Cause: the design marks stand-in buttons `hidden`, but `.btn { display: inline-flex }` overrides the attribute, and the app had copied that. The same made two "Pay" buttons (and two "Hold these seats" buttons) show at once on every page load. Fixed with one `[hidden]` rule (ADR 0018); the pixel comparison applies the same rule to the design page, still 20 of 20 identical.
